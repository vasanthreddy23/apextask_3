# Task 3: Data Visualization & Dashboarding

## Objective
Build an interactive executive dashboard with 6–8 visuals to analyze sales performance and customer insights.

## Deliverables
- **Dashboard File**: `task3_dashboard.pbix` (Power BI)
- **Python Visuals**: Supporting plots in `.png`/`.html`
- **Screenshots**: Dashboard visuals for quick preview

## Dashboard Highlights
- KPI Cards: Total Sales, Total Customers, Total Orders
- Sales Trend: Line chart showing revenue over time
- Category Breakdown: Donut chart of sales by item
- Top 10 Products/Customers: Bar chart with filters
- Interactive Filters: Date, Item, Name slicers
- Geographic Map (if location data available)

## How to Run
1. Open `task3_dashboard.pbix` in Power BI Desktop.
2. Use slicers to filter by Date, Item, or Customer.
3. Explore KPI cards and visuals for insights.
4. Published version available via Power BI Service link (see repo description/comments).
